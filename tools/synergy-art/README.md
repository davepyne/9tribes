# Synergy Card Art — Generation Pipeline

Generated by `scripts/generateSynergyArtPrompts.mjs`. Re-run that script
whenever pair-synergies.json or emergent-rules.json changes.

## Files

- `prompts.json` — full structured manifest (filename + prompt + negative)
- `prompts.csv` — flat CSV for paste-into-batch UIs
- `comfyui-batch.txt` — `filename||prompt` lines for the ComfyUI batch loop

## How to run with a local ComfyUI server

1. Start ComfyUI with the API enabled (default: `http://127.0.0.1:8188`).
2. Use `tools/synergy-art/comfyui-runner.mjs` (see below) and point it at
   the server URL plus a Flux workflow JSON exported from the ComfyUI UI.
3. The runner reads `prompts.json`, queues each entry, and saves the result
   directly into `web/public/assets/synergy-cards/{pairs,triples}/` so the
   in-game art resolver picks it up on next reload.

## Style anchors (locked)

The same style prefix is applied to every prompt to keep the set cohesive:

> tarot card illustration, woodcut and ink with desaturated parchment wash,
> symmetrical heraldic composition, central iconography, ornate filigree
> border, aged paper texture, muted earth-tones with one accent color,
> arcane and martial, painterly rendered, no text, no letters, no numbers, no UI

## Output paths

- Pairs (~55 unique unordered domain pairs)
  → `web/public/assets/synergy-cards/pairs/{domainA}_{domainB}.jpg`
  → alphabetical filenames so the resolver can match deterministically.

- Triples (~99 = 9 factions × 11 rules)
  → `web/public/assets/synergy-cards/triples/{factionId}_{ruleId}.jpg`
  → bespoke per-faction art for the splash rares.

If a file is missing the SynergyCard art resolver falls back to the
procedural SVG sigil — never throws.

## Recommended Flux settings (starting points, tune per workflow)

- Model: Flux.1-dev or Flux.2 dev (depending on which you have loaded)
- Sampler: euler / dpmpp_2m
- Steps: 24-32
- CFG / guidance: 3.5-5.0 (Flux likes lower CFG than SDXL)
- Resolution: 832 × 1216 (portrait) or 768 × 1024 (3:4) — frame the
  composition for the art-window aspect (ours crops to ~16:9 with a vignette)
- Seed: random per image; record the seeds you keep for reproducibility
